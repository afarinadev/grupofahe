# Grupo FAHE · web

Web estática de Grupo FAHE (Caldas de Reis, Camino Portugués) con sus cuatro marcas:

| Página | Contenido |
| --- | --- |
| `index.html` | Grupo FAHE: quiénes somos, las empresas, contacto |
| `peregrinos.html` | Albergue Urraca y Hospederías do Camiño: reserva, servicios, etapa, opiniones |
| `caldasgo.html` | Caldas GO: reparto de paquetería, mochilas y traslados |
| `infaes.html` | Infaes: gestión y promoción de inmuebles |

Solo HTML, CSS y JavaScript, sin dependencias ni compilación. Los formularios abren WhatsApp con el mensaje ya escrito.

## Verla en local

```bash
php -S localhost:8090 -t .
```

## Pendiente

Los bloques marcados con `<!-- PENDIENTE -->` en el HTML: fotos reales, logos en alta calidad, datos de las hospederías, condiciones del transporte de mochilas, servicios de Infaes, número REAT de la Xunta y páginas legales.
